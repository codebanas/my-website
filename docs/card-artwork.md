# Card artwork

Created with the built-in image generation tool. Project assets are saved in
`public/cards/art-{blue,green,pink,yellow,purple}.png` and served with Next.js image
optimization. Amber and teal cards reuse the yellow and purple artwork with CSS
hue filters.

Each image used this prompt, replacing `{texture}` with its description below:

> Use case: stylized-concept. Asset type: abstract texture artwork for the lower panel of a website card. Generate a single square edge-to-edge texture image. {texture} Flat front-facing artwork, no perspective, no borders, no mockup, no typography, no logos, no objects, no UI. The texture must fill the whole canvas. Match understated experimental editorial graphic-design print textures.

- Blue: Periwinkle and cornflower blue ground, broad soft silvery lavender cloud-like dry brush marks, grainy distressed photocopy and woven fabric texture, hazy irregular horizontal bands.
- Green: Muted sage gray-green ground with soft luminous pale lime caustic ripples, like light refracting through water onto satin, softly blurred flowing organic diagonal ribbons, fine film grain.
- Pink: Orchid pink ground with darker magenta abstract liquid squiggles, loops and fluid ripples, shallow embossed silk appearance, grainy photocopy print texture.
- Yellow: Warm butter yellow ground with many thin charcoal gray wavy parallel horizontal lines, organic gently undulating rhythm, slight screenprint grain, graphic minimal pattern.
- Purple: Lavender lilac ground with dark violet fine warped square mesh, flowing distorted grid of many tiny squares, subtle lime accents, wavy fabric-like surface and fine grain.
